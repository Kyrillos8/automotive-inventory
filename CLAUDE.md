# CLAUDE.md — Automotive Engine Parts Inventory (مخزن قطع غيار الموتور)

Arabic-first (RTL), **offline-only** Flutter app for one admin managing a piston-ring / piston /
engine-parts wholesale & retail business on a single Android device. SQLite on the device is the
source of truth. No server, no Firebase, no network features.

Full business requirements: `docs/REQUIREMENTS.md`. Rules, assumptions, limitations: `docs/PLAN.md`.

## Stack
Flutter (stable, CI uses latest) · Dart 3 · Drift (SQLite) · Riverpod 2 · GoRouter 14 ·
flutter_localizations (default locale `ar-EG`). Extra: share_plus 10, file_picker 8, crypto.

## Layout (feature-first)
```
lib/
  main.dart                 opens DB, loads settings, post-restore reconcile, PIN lock flag
  app/                      app.dart (MaterialApp.router, RTL, LockGate), router.dart (5 tabs + /more/*), theme/
  core/
    database/               tables.dart (ALL tables), app_database.dart (migrations, indexes, seeds, doc numbers)
    utils/                  money.dart (Money/Qty), search_normalizer.dart (Arabic normalization)
    widgets/                common.dart (Fmt, runAction, confirm, MoneyField, QtyField, FutureLoader…), state_views.dart
    backup/                 backup_service.dart (VACUUM INTO, validate, full-replace restore)
    security/               pin_service.dart (salted SHA-256), lock_screen.dart
    errors/                 BusinessException (Arabic, user-facing)
  features/<name>/          <name>_service|repository.dart (business logic) + presentation/ (screens)
    products/  inventory/  purchasing/  customers/  sales/  reports/  dashboard/  settings/  setup/  more/
test/                       money, search_normalizer, invoice_draft (pricing), database_test (acceptance tests A–K, O)
tool/compile_sdk_fix.gradle forces plugin compileSdk 36 (needed by file_picker 8); applied from android/build.gradle.kts
```
`android/` is generated by `flutter create` in CI if missing (see workflow).

## Non-negotiable rules
- **Money** = `int` piastres (`Money`), **quantity** = `int` milli-units (`Qty`, 1 unit = 1000). Never doubles, never formatted strings in storage.
- **Stock changes only through `InventoryService.apply()`**, inside the posting document's transaction. UI never writes `stock_balances` / `stock_movements`.
- Posting checks `status == draft` inside the transaction (no double posting). Posted documents are never edited or deleted — correct with returns, payment reversals, adjustments or void.
- Negative stock is blocked. Opening stock allowed once per product (also a partial unique index).
- Costing: moving weighted average. `sale_lines.unit_cost_at_sale` is the COGS snapshot.
- Pricing: customer type sets the default mode (walk-in = retail). Mode switches update only non-manual lines; if manual overrides exist the UI must ask keep/reset. Logic lives in `features/sales/invoice_draft.dart` (pure, unit-tested).
- Search: `products.search_text` is a normalized key rebuilt by `ProductRepository.rebuildSearchText()` whenever product, tags, vehicles or brand change. Every query term must match (AND); exact SKU/barcode/T.C ranks first.
- Gross profit only — never label anything "net profit".
- Schema changes: bump `schemaVersion` in `app_database.dart` and add an `onUpgrade` step. Never drop business tables.
- UI text is Arabic; codes/SKUs/numbers shown with `TextDirection.ltr` where needed.

## Gotchas learned from CI
- `package:intl` exports its own `TextDirection` → import intl as `show DateFormat` in UI files.
- When importing drift with `show`, include the extensions you use: `BooleanExpressionOperators` (`&`, `|`), `StringExpressionOperators` (`like`). Don't import drift unrestricted in UI files (clashes with Flutter `Column`, `Table`).
- file_picker ≥ 11 breaks plugin registration with this Flutter; ≥ 13 conflicts with share_plus 10. Keep file_picker 8 + `tool/compile_sdk_fix.gradle`.

## Building & testing
The Claude cloud sandbox **cannot download the Flutter SDK** (storage.googleapis.com / pub.dev blocked).
All compiling happens in GitHub Actions (`.github/workflows/build-apk.yml`) on every push to `main`:
1. `flutter create` (if no android/), `pub get`, `build_runner`, `flutter analyze`, `flutter test`, `flutter build apk --release`.
2. Logs are pushed to the **`ci-logs` branch** (GitHub log downloads are blocked from the sandbox):
   `git fetch origin ci-logs && git show origin/ci-logs:summary.txt` then `4-analyze.txt`, `5-test.txt`, `6-build.txt`.
3. On success the APK is attached to the `latest-build` release. Download via
   `gh api -H "Accept: application/octet-stream" repos/Kyrillos8/automotive-inventory/releases/assets/<id>`.
Watch a run: `gh run list -R Kyrillos8/automotive-inventory -L 1` then `gh run watch <id>` (GraphQL is blocked; use REST via `gh api`).

Locally (with Flutter installed):
```
flutter pub get && dart run build_runner build --delete-conflicting-outputs
flutter analyze && flutter test && flutter build apk --release
```
`lib/core/database/app_database.g.dart` is generated — never edit it, and it is not committed.

## Known limitations / backlog
No biometric unlock, alternative units/conversions, taxes, PDF invoices, CSV import of opening stock,
barcode scanning, applying customer credit to another invoice. Release APK is debug-signed.
